# Security policy

Please report suspected vulnerabilities privately to the repository owner through GitHub's private vulnerability reporting feature. Include the affected version, reproduction steps and impact. Do not post exploit details, real customer PDFs, identity documents or personal data in public issues.

This application processes files locally and does not upload PDFs. Treat untrusted PDFs carefully and keep dependencies updated. Password-protected PDFs are rejected in this version. Do not use the tool to modify signed or archival records without checking the resulting document: rewriting a signed PDF invalidates its signature, and complex document-level features are not guaranteed to survive.
